# Organ Explainer on Meta Quest

Quest mode puts the healthy organ and the patient's organ on a small table.
On Quest 3 / 3S / Pro you see them in your real room (mixed reality).
On Quest 2 you can choose mixed reality (black-and-white passthrough) or a calm VR room.

For education only. Not for diagnosis.

## Way A: no install (works on any Quest, no settings to change)

1. Put on the headset. Open **Browser** from the app bar.
2. Type this address and press Enter:
   `bhanushankarprajwal-hue.github.io/organ-explainer-ar/xr.html`
3. Pick an organ. Press **Enter mixed reality** (or **Enter VR**).
4. Press **Allow** if the headset asks.
5. Tip: add a bookmark so next time it is one click.

## Way B: install the APK

Download: https://github.com/bhanushankarprajwal-hue/organ-explainer-ar/releases/download/quest-apk/OrganExplainer-Quest.apk

Every Quest needs **Developer Mode** turned on once before it can install an APK.
Only the person whose Meta account owns the headset can turn it on.

1. On the owner's phone, open the **Meta Horizon** app.
2. Tap **Devices** → pick the headset → **Headset settings** → **Developer mode** → turn it on.
   (It may ask to create a free developer organisation at developers.meta.com first.)
3. Connect the headset to a laptop with a USB-C cable. In the headset, press **Allow USB debugging**.
4. On the laptop, install **Meta Quest Developer Hub** (or **SideQuest**).
5. Drag `OrganExplainer-Quest.apk` onto it. Wait for "Installed".
6. In the headset: **App library** → top-right filter → **Unknown sources** → **Organ Explainer**.

The app opens Quest mode in the Meta Quest Browser. That browser runs the VR part
(hand tracking, controllers, passthrough). The headset needs Wi-Fi.

## How to use it inside the headset

- Point at a number and press the trigger (or pinch two fingers) to learn about that part.
- Point at an organ and hold the trigger or grip (or pinch) to pick it up and turn it.
- Hold one organ with both hands and pull apart to make it bigger.
- Thumbstick: left/right turns, up/down zooms the organ you point at.
- Floating panel: Outside / Inside, Explain my case (step-by-step tour), Reset, ✕ to exit.

## Show one patient's case

On a phone or laptop, open **My Report**, fill in or scan the report, add notes, then press
**Open in VR headset**. Open that same link in the headset browser.
